# battery-conservation-toggle

A lightweight Linux CLI utility to auto-detect hardware and toggle battery charge caps (80% / 100%) across Lenovo, ASUS, Dell, Framework, System76, and more.

## Setup
1. sudo nano /usr/local/bin/battery-toggle
2. sudo chmod +x /usr/local/bin/battery-toggle
