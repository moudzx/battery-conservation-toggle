# battery-conservation-toggle

A lightweight Linux CLI utility to auto-detect hardware and toggle battery charge caps (80% / 100%) across Lenovo, ASUS, Dell, Framework, System76, and more.

## Check Battery Capacity

[How to check battery capacity on Linux](https://youtu.be/RjornIF4JBw) <br>
[guide.pdf](https://github.com/moudzx/battery-conservation-toggle/blob/main/guide.pdf)

## Setup
1. sudo nano /usr/local/bin/battery-toggle
2. paste [battery-toggle](https://github.com/moudzx/battery-conservation-toggle/blob/main/battery-toggle)
3. sudo chmod +x /usr/local/bin/battery-toggle
